Coding Project — 42 School

miniRT

A raytracing engine built from scratch in C — casting rays pixel by pixel to render a scene defined by a simple map file: spheres, planes, and lights. Passed with bonus.

01

The Problem

No engine, no library — just math

Rendering a realistic 3D scene with no game engine and no rendering library: just C, a window buffer via minilibX, and the linear algebra needed to figure out where every ray of light actually goes when it hits a sphere, a plane, or a cylinder defined in a scene map.

02

The Build

Casting rays, pixel by pixel

The scene itself is just a map — a text file listing a camera, one or more lights, and objects (spheres, planes, cylinders) with their positions and colors. My renderer parses that map, then for every pixel in the viewport casts a ray into the scene, calculates its intersections with those objects, and computes lighting, shadows, and reflections at each hit point.

03

The Result

Passed with bonus

A working raytracer that reads a scene map and renders it with accurate lighting, shadows, and reflections — built entirely from first principles in C, with no external rendering library to lean on.
